# Member Memory

## What to Track

Only store information that changes how you'd interact with someone. Don't store everything.

**Worth storing:**
- What they're building or working on
- Their Discord ID (for @mentions)
- Topics they engage with
- Last follow-up date + whether they responded
- Things they've said they're not interested in

**Not worth storing:**
- One-off comments with no follow-up value
- General reactions (👍, lol, etc.)
- Things they said once that didn't become a pattern

## Format in MEMORY.md

```
### Members

**[Name/handle]** | <@DISCORD_ID>
- Building: [what they're working on]
- Interests: [topics they engage with]
- Last follow-up: [date] | responded: [yes/no]
- Notes: [anything else relevant]
```

## Keeping It Clean

- MEMORY.md stays under 100 lines total
- If someone hasn't engaged in 60+ days, remove their entry
- Update in place — don't append new entries for the same person
- If you don't have their Discord ID yet, leave it blank until you see it in a message

## Engagement Tracking

At the bottom of MEMORY.md, keep a short log:

```
### Engagement Log

- [topic/post type]: [high/low] engagement — [date]
```

Max 10 entries. Drop the oldest when you add a new one.

# Post Quiz

## Writing the Question

- Pick a concept a newcomer would actually benefit from knowing (gas fees, wallets, consensus, L2s, etc.)
- Write exactly 3 options: one correct, two plausible-sounding wrong answers
- Label them A, B, C — no D
- Keep the question to one sentence
- Never use jargon in the question itself; save that for the follow-up

**Format:**
```
Quick one — [question]?
A) [option]
B) [option]
C) [option]
```

## Following Up

Post the answer after people respond, or after ~3 hours if no responses.

**Format:**
```
It's [letter] — [correct answer]. [One sentence explaining why in plain English.] [Follow-up question that opens real discussion.]
```

If someone got it wrong: "Close! It's actually [X] — easy to mix up with [Y]."
Never say "great answer" or "good try." Just move the conversation forward.

## After the Quiz

- If it got good engagement: note the topic in MEMORY.md as "high engagement"
- If zero responses after 3 days: note it as "low engagement — try different format"
- The follow-up question is mandatory — the quiz is just a hook
